명령행과 정규식

명령행(:)에서 파일 전체를 다루는 강력한 정규식 치환과 필터 명령을 배웁니다.

명령행의 세계

:(콜론)으로 시작하는 명령행은 vim의 파워 유저 영역입니다. 파일 전체, 선택 영역, 범위를 지정해 명령을 실행할 수 있습니다.

범위(Range)

명령 앞에 범위를 붙이면 “어디에” 적용할지 정할 수 있습니다.

:5            → 5번 줄로 이동
:5,10d        → 5~10번 줄 삭제
:.,$d         → 현재 줄~끝 삭제
:1,.s/foo/bar → 1번~현재 줄 치환
:%s/foo/bar   → 전체 치환
:'<,'>s/...   → 비주얼 선택 영역

.는 현재 줄, $는 마지막 줄, %는 파일 전체를 뜻합니다.

정규식 기초

vim 정규식은 grep과 비슷하지만 특수 문자가 다릅니다.

패턴 의미
. 임의의 문자
* 앞 문자의 0회 이상
\+ 앞 문자의 1회 이상
\? 앞 문자의 0 또는 1회
\(...\) 그룹
\1 첫 번째 그룹 참조
\< \> 단어 경계
[a-z] 문자 클래스

매번 \를 붙이기 번거롭다면 very magic 모드를 씁니다.

:%s/\v(...)/\1/g

\v 이후부터는 ( ) + ? | 등을 이스케이프 없이 쓸 수 있습니다.

실전 치환 패턴

:%s/\v(\w+)@<=_(\w+)/\1\u\2/g   → snake_case를 camelCase로 (예)
:%s/\v(\w+)/\U\1/               → 대문자화
:%s/^\s*\n//                    → 빈 줄 제거
:%s/\v\s+$//                    → 줄 끝 공백 제거

템플릿 변환, 문자열 대소문자 통일, 포맷 정리 등에 유용합니다. \u는 다음 글자 대문자, \U는 이후 모두 대문자.

명령행에서 셸과 연동

:!ls              → 셸 명령 실행
:r !date          → 셸 출력을 버퍼에 삽입
:%!sort           → 버퍼 전체를 sort 결과로 교체
:2,$!sort -t',' -k2   → 범위 필터

:%!{command}는 버퍼를 파이프로 처리하는 고급 기능입니다. 정렬, 유니크, 포맷 등 어떤 것도 가능합니다.

히스토리

명령행 히스토리는 Ctrl+p/Ctrl+n으로 탐색하고, q:로 명령 히스토리 창을 엽니다.

연습

  1. :%s/\v\s+$//로 줄 끝 공백 제거
  2. :1,.s/foo/bar/g로 범위 치환
  3. :%!sort로 정렬
  4. q:로 명령 히스토리 확인

다음 강의는 텍스트 객체와 . 반복으로 편집 효율을 극대화합니다.
