텍스트 입력 — i a o와 Insert 모드

Insert 모드로 진입하는 다양한 방법을 배웁니다.

Insert 모드 진입

Normal 모드에서 다음 키를 누르면 Insert 모드가 됩니다. 어디에 커서가 놓이느냐가 다릅니다.

키 커서 위치
i 현재 커서 앞(insert)
a 현재 커서 뒤(append)
I 현재 줄의 맨 앞
A 현재 줄의 맨 끝
o 아래에 새 줄 만들고 이동
O 위에 새 줄 만들고 이동 
Hello World
    ^

커서가 World의 W에 있을 때:

  • i를 누르면 W 앞에 입력
  • a를 누르면 d 뒤에 입력
  • A를 누르면 줄 끝에서 입력

입력 중이라도 방향 이동은 가능

Insert 모드에서도 화살표 키와 Ctrl+h(한 글자 삭제), Ctrl+w(단어 삭제), Ctrl+u(줄 시작까지 삭제)가 동작합니다. Backspace도 사용할 수 있습니다.

Esc로 Normal 모드 복귀

Insert 모드 → <Esc> → Normal 모드

<Esc> 외에도 Ctrl+[ 가 동일한 기능을 합니다. 손이 머무는 위치에 따라 편한 것을 쓰면 됩니다.

자주 하는 실수: 입력하다가 방향을 바꾸려고 화살표를 오래 누르게 됩니다. vim스러운 방법은 <Esc>로 나와서 hjkl로 이동한 뒤 다시 입력하는 것입니다.

실전 흐름

  1. gg로 첫 줄 이동
  2. A로 줄 끝에서 입력 시작
  3. 문장 입력 후 <Esc>
  4. o로 아래 새 줄에서 입력
  5. <Esc> 후 :wq로 저장 종료

팁: 명령이 섞일 때는 조합으로

daw   → delete a word  : 단어 하나 삭제
ciw   → change inner word : 단어 교체

이처럼 d(delete)와 c(change)는 다음 강의에서 자세히 다룹니다.
