기본 과정 마무리 — vimtutor와 실전 전략

vimtutor 활용법과 vim을 실무에 적용하는 단계별 전략을 배웁니다.

vimtutor

vim은 공식 내장 튜토리얼 vimtutor를 제공합니다.

$ vimtutor

화면의 지시를 따라가며 기본 명령을 직접 연습할 수 있는 약 30분 분량의 자료입니다. 한국어 버전도 있습니다.

$ vimtutor ko

지금까지 배운 흐름 정리

  1. 모드 이해 — Normal / Insert / Visual / Command-line
  2. 이동 — hjkl, w b e, gg G, $ 0, %
  3. 입력 — i a I A o O, <Esc>
  4. 삭제/변경 — d c x, 모션 결합
  5. undo/redo — u, Ctrl+r
  6. 복사/붙여넣기 — y p, 레지스터 예고
  7. 검색/치환 — / ? * :s
  8. 파일 — :w :q :e
  9. 비주얼/블록 — v V Ctrl+v

이 목록만으로도 충분히 “vim으로 코드를 편집하는 사람”이 될 수 있습니다.

실전 진입 전략

vim을 단숨에 익히려 하지 마세요. 한 달 동안 조금씩 바꾸는 전략이 효과적입니다.

  1. 1~2주: 터미널에서 vim으로 메모·설정 파일 편집. 화살표를 hjkl로 바꾸기.
  2. 3~4주: IDE에 vim 모드(예: VS Code Vim) 활성화. 코드 작성은 평소처럼, 수정·이동만 vim으로.
  3. 그다음: f t . ; 같은 고효율 이동을 하나씩 추가.
  4. 중급 이후: 매크로, 레지스터, 명령행 조합으로 반복 작업 자동화.

IDE vim 모드

  • VS Code: Vim 확장
  • JetBrains: IdeaVim
  • Neovim 사용자는 nvim으로 확장 생태계로 이동

IDE vim 모드는 실제 vim과 호환되는 키바인딩을 제공하면서 자동 완성·디버깅은 IDE 그대로 쓸 수 있어 진입장벽이 낮습니다.

다음 단계

기본 과정을 마쳤습니다. 이제 사이트의 심화 섹션으로 넘어가세요.

  • 매크로로 반복 작업을 자동화
  • 버퍼·탭·분할창으로 여러 파일 다루기
  • 레지스터·마크로 클립보드와 북마크처럼 사용
  • 명령행과 정규식으로 강력한 치환

기억하세요. vim의 정체는 “손가락이 기억하는 것”입니다. 매일 10분씩 사용하는 것이 가장 빠른 길입니다.
