버퍼·윈도우·탭 — 여러 파일 다루기

여러 파일을 동시에 편집하는 버퍼, 분할창, 탭 개념을 배웁니다.

버퍼(Buffer)

vim에서 파일을 열면 버퍼로 메모리에 로드됩니다. 여러 파일을 열면 여러 버퍼가 생기고, 화면에는 그중 하나가 보입니다.

$ vim a.txt b.txt c.txt
명령 동작
:ls 버퍼 목록 표시
:bn / :bp 다음 / 이전 버퍼
:b3 3번 버퍼로 이동
:bd 버퍼 닫기
:e file 새 파일을 새 버퍼로 열기

%는 현재 버퍼, #는 이전 버퍼를 뜻합니다. Ctrl+^로 이전 버퍼와 빠르게 전환할 수 있습니다.

윈도우(분할창)

하나의 화면을 여러 창으로 나누어 동시에 다른 버퍼를 볼 수 있습니다.

명령 동작
:split or :sp 가로 분할 (위/아래)
:vsplit or :vsp 세로 분할 (왼쪽/오른쪽)
:new / :vnew 새 빈 버퍼로 분할
Ctrl+w w 다음 창으로 이동
Ctrl+w h/j/k/l 방향으로 창 이동
Ctrl+w = 창 크기 균등
Ctrl+w _ 창 최대화(세로)
:q 현재 창 닫기

핵심 규칙: Ctrl+w 다음에 방향키. Ctrl+w를 “창 전용 리더 키”로 기억하세요.

탭(Tab)

탭은 서로 다른 창 레이아웃을 묶는 작업 공간입니다.

명령 동작
:tabnew file 새 탭에서 파일 열기
gt / gT 다음 / 이전 탭
:tabn / :tabp 다음 / 이전 탭
:tabs 탭 목록

여러 파일을 “창”으로 한 화면에, 관련 있는 파일 묶음은 “탭”으로 구분하는 것이 일반적입니다.

분할창 실전 활용

:sp             → 위/아래로 나눔
:vsp %          → 현재 파일을 세로로 나누기
Ctrl+w w        → 창 전환
:bn             → 아래 창에서 다음 버퍼
  • 코드와 테스트 파일을 나란히
  • 원문과 번역을 나란히
  • diff를 나란히

로컬 vim에서 연습하기

창과 탭은 여러 파일을 동시에 띄울 수 있어야 의미가 있으니, 아래는 로컬 vim으로 직접 해보세요.

  1. :sp 후 :vsp로 네 칸 만들기
  2. 각 창에서 :bn으로 버퍼 전환
  3. Ctrl+w h/j/k/l로 창 이동
  4. gt/gT로 탭 전환
  5. :ls로 버퍼 목록 확인

다음 강의는 마크와 레지스터로 북마크와 클립보드를 넘어서는 기능을 배웁니다.
