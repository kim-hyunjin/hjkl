vim 시작하기 — 처음 만나는 편집기

vim을 왜 배우는지, 그리고 첫 화면과 모드 개념을 이해합니다.

vim은 왜 배울까?

vim은 키보드만으로 텍스트를 빠르게 편집하기 위해 만들어진 편집기입니다. 마우스를 쓰지 않고 손가락이 키보드 위에 머무는 동안 거의 모든 조작이 가능하기 때문에, 익숙해지면 코드 작성·서버 작업·git 커밋 메시지 작성 등에서 생산성이 크게 올라갑니다.

vim은 다음과 같은 환경에서 만나게 됩니다.

  • 터미널에서 vim 실행
  • git commit 시 메시지 작성 (기본 편집기)
  • 서버 접속 후 원격 파일 편집
  • VS Code, IntelliJ 등 IDE의 vim 모드

vim 실행과 첫 화면

터미널에 vim을 입력하면 빈 편집기가 열립니다. 특정 파일을 열려면 파일명을 붙입니다.

$ vim hello.md

hello.md가 없으면 새 파일로 열립니다. 저장했을 때 비로소 파일이 생깁니다.

모드(mode)의 개념이 전부입니다

vim의 핵심은 모드에 있습니다. 대부분의 편집기는 “타이핑 = 입력”이지만, vim은 모드에 따라 키 입력의 의미가 달라집니다.

모드 역할 진입 방법
Normal (일반) 명령 실행, 이동 <Esc>
Insert (입력) 텍스트 입력 i, a, o 등
Visual (비주얼) 영역 선택 v, V, Ctrl+v
Command-line (명령행) :w 같은 명령 실행 :, /, ?

vim을 시작하면 기본으로 Normal 모드입니다. 여기서 i를 누르면 Insert 모드가 되고, 다시 <Esc>로 Normal 모드로 돌아옵니다.

Tip: <Esc>는 vim 사용 중 가장 자주 누르는 키입니다. 헤매면 일단 Escape부터 누르세요.

첫 명령어 3개

명령 동작
:q vim 종료 (변경 사항이 없을 때)
:q! 변경 사항을 버리고 종료
:wq 저장하고 종료

:q를 눌렀는데 저장하지 않은 변경이 있으면 vim이 거부합니다. 그때는 :q! 또는 :wq를 사용하면 됩니다.

정리

  • vim은 모드 기반 편집기이고, 시작하면 Normal 모드입니다.
  • i로 입력, <Esc>로 명령 모드 복귀.
  • 종료는 :q, 강제 종료는 :q!, 저장 종료는 :wq.

다음 강의에서는 Normal 모드에서 커서를 움직이는 법을 배웁니다.
