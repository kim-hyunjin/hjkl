비주얼 모드 — v V Ctrl+v

텍스트를 선택하고 블록 편집하는 비주얼 모드를 배웁니다.

비주얼 모드란

비주얼(Visual) 모드는 텍스트를 선택하는 모드입니다. 선택 영역을 만든 뒤 삭제, 복사, 치환, 들여쓰기 등을 적용합니다.

키 선택 단위
v 문자 단위
V 줄 단위
Ctrl+v 블록(세로) 단위

기본 사용법

v          → 비주얼 모드 시작
(이동 명령) → 선택 확장
d          → 선택 영역 삭제
y          → 선택 영역 복사

예를 들어 V로 줄 선택 후 j로 아래로 확장하고 y를 누르면 여러 줄이 복사됩니다. 그다음 p로 붙여넣습니다.

선택 반대편으로 이동

o    → 선택 영역의 반대쪽 끝으로 커서 이동
gv   → 마지막 선택 영역을 다시 선택

o는 선택 시작점과 끝점을 오가며 줄일 수 있어 유용합니다.

들여쓰기

비주얼 선택 후 > 또는 <로 들여쓰기/내어쓰기를 합니다.

V
j        → 2줄 선택
>        → 들여쓰기

. 키로 같은 들여쓰기를 반복할 수 있습니다.

블록 편집 (Ctrl+v)

Ctrl+v는 세로 블록을 선택합니다. 여러 줄의 같은 위치를 한 번에 편집하는 최강의 기능입니다.

01  Apple
02  Banana
03  Cherry
  1. Ctrl+v로 블록 모드
  2. j와 l로 세로 영역 선택
  3. I로 블록 앞에 삽입 (맨 위 줄에 삽입)
  4. 텍스트 입력 후 <Esc>
>> 01  Apple
>> 02  Banana
>> 03  Cherry

블록 선택 후 A를 누르면 각 줄의 뒤에 텍스트가 추가됩니다. 동시에 여러 줄 뒤에 ,를 붙이는 작업이 순식간에 끝납니다.

비주얼 치환

v         → 단어 선택
:s/foo/bar → 선택 영역 내 치환

입력하면 :'<,'>s/foo/bar로 자동 변환되어 선택 영역에만 적용됩니다.

연습

  1. V로 여러 줄 선택 후 y, p
  2. Ctrl+v로 세로 블록 선택 후 I로 앞에 # 추가
  3. 반대로 A로 각 줄 끝에 ; 추가
  4. gv로 이전 선택 복원

비주얼 모드는 특히 여러 줄을 동시에 다룰 때 위력을 발휘합니다. 다음 강의는 기본 과정의 마무리로 vimtutor와 실전 진입 전략을 알려드립니다.
