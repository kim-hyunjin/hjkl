삭제와 변경 — d와 c 명령

모션과 결합해 텍스트를 지우고 바꾸는 방법을 배웁니다.

삭제 명령 d

d는 delete의 약자입니다. d 뒤에 모션을 붙여 범위를 정합니다.

명령 동작
x 커서 글자 하나 삭제
dw 단어 하나 삭제
d$ 커서부터 줄 끝까지 삭제
d0 커서부터 줄 처음까지 삭제
dd 현재 줄 전체 삭제
d3w 단어 3개 삭제
dG 커서부터 파일 끝까지 삭제 
The quick brown fox

커서가 quick의 q에 있을 때 dw를 누르면 quick 가 지워져 The brown fox가 됩니다. 공백까지 포함해서 지운다는 점을 기억하세요.

d 뒤에 숫자+모션도 한 번에 쓸 수 있습니다. d2w는 단어 2개 삭제.

변경 명령 c

c는 change의 약자입니다. 삭제한 뒤 Insert 모드로 전환됩니다.

명령 동작
cw 단어 교체 (삭제 후 입력)
c$ 커서부터 줄 끝까지 교체
cc 현재 줄 전체 교체
ciw 커서 안쪽 단어 교체 
RED green
  • ciw → BUG green (단어 전체가 바뀜)
  • cw → 단어 교체에 커서가 있던 위치부터 적용되는 미세한 차이가 있습니다.

ciw는 단어 안쪽(inner word)만 지우고, 공백과 주변을 보존합니다. 실무에서 가장 많이 쓰는 변경 명령입니다.

줄 지우기 패턴

dd        → 줄 삭제
3dd       → 3줄 삭제
d$        → 줄 끝까지 삭제
D         → d$ 와 동일
dj        → 현재 줄과 아래 줄 삭제

삭제된 텍스트는 레지스터에

vim에서 삭제한 내용은 레지스터에 저장되어 p로 붙여넣을 수 있습니다. dd 후 p를 누르면 방금 지운 줄이 아래에 다시 나타납니다. (레지스터는 심화에서 자세히 다룹니다.)

주의: x와 X

키 동작
x 커서 위치 글자 삭제
X 커서 앞 글자 삭제

연습

  1. x로 글자 삭제
  2. dw로 단어 삭제
  3. dd로 줄 삭제 후 u로 되돌리기
  4. ciw로 단어 교체

삭제 후 u하면 되돌릴 수 있으니 부담 없이 눌러보세요. u(undo)는 다음 강의에서 배웁니다.
