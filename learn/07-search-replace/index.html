검색과 치환 — / ? :s

파일 안에서 원하는 문자열을 찾고 바꾸는 방법을 배웁니다.

검색

Normal 모드에서 /를 누르고 검색어를 입력한 뒤 Enter를 누르면 아래 방향으로 검색합니다.

/foo
키 동작
/pattern 아래 방향 검색
?pattern 위 방향 검색
n 다음 검색 결과로 이동
N 이전 검색 결과로 이동
* 커서 아래 단어를 아래 방향 검색
# 커서 아래 단어를 위 방향 검색

검색 결과는 하이라이트됩니다. 하이라이트가 거슬리면 :nohlsearch로 지웁니다.

*는 코드에서 변수 이름을 찾을 때 매우 유용합니다. 커서를 변수 위에 놓고 *만 누르면 됩니다.

치환

치환은 명령행에서 :s(substitute)를 사용합니다.

:s/old/new/        현재 줄의 첫 번째 old만 교체
:s/old/new/g       현재 줄의 모든 old 교체
:%s/old/new/g      파일 전체에서 교체
:%s/old/new/gc     파일 전체 교체 전에 확인

%는 “파일 전체”를 뜻하는 범위입니다. 범위를 다르게 줄 수도 있습니다.

:2,5s/old/new/g    2~5번째 줄에서 교체
:'<,'>s/old/new/g  비주얼로 선택한 영역에서 교체

:'<,'>는 비주얼 모드에서 선택하고 :s/...를 입력하면 자동으로 붙는 범위입니다.

확인 옵션 c

:c 플래그를 붙이면 교체할 때마다 물어봅니다.

:%s/foo/bar/gc
replace with bar (y/n/a/q/l/^E/^Y)?
  • y 교체
  • n 건너뜀
  • a 모두 교체
  • q 중단
  • l 이번만 교체하고 중단

정규식 활용

치환은 기본적으로 정규식입니다.

:%s/^/  /g           줄 앞에 공백 2개 추가
:%s/$/,/g            줄 끝에 콤마 추가
:%s/\v(red|blue)/color/g    빨강/파랑을 color로
:%s/\<word\>/WORD/g  단어 경계를 지키며 교체

\v(very magic)를 쓰면 ( ) |를 이스케이프 없이 쓸 수 있어 정규식이 읽기 편해집니다.

특수 문자

:/\<word\>     단어 경계 검색
:/^TODO        줄 시작 검색
:/error$       줄 끝 검색
:/\v\d{2,4}    숫자 2~4개 검색

연습

  1. /vim으로 검색 후 n/N으로 이동
  2. *로 커서 아래 단어 검색
  3. :%s/vim/Vim/g로 파일 전체 치환
  4. :%s/Vim/VIM/gc로 확인하며 치환

검색과 치환을 익히면 긴 파일도 자유롭게 다룰 수 있습니다. 다음 강의는 저장·종료와 파일 다루기입니다.
