파일 전체 치환

정규식으로 파일 전체에서 일관되게 바꾸는 챌린지입니다.

문제안내

목표

다음 텍스트에서 단어 경계를 지켜 cat을 dog로 바꾸세요.

cat catalog concatenate cat catty cat

결과:

dog catalog concatenate dog catty dog

조건

  • catalog, concatenate, catty는 바뀌면 안 됩니다
  • :%s 치환 사용
  • g 플래그 필수

예상 결과

dog catalog concatenate dog catty dog

:%s///g, \<\>
