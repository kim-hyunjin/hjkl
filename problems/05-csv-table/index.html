CSV를 표로 정리하고 특정 열만 추출

비주얼 블록과 필터로 CSV 데이터를 다루는 실전 워크플로를 배웁니다.

상황

CSV 파일에서 일부 열만 보거나, 콤마가 섞인 필드를 정리해야 합니다.

id,name,score
1,Alice,95
2,Bob,87
3,Charlie,92

특정 열만 잘라내기

Ctrl+v 블록 선택으로 여러 줄의 같은 위치를 복사할 수 있습니다.

  1. 커서를 id 열 시작에 놓고 Ctrl+v
  2. j로 여러 행 선택
  3. y로 복사
  4. 새 버퍼에서 p로 붙여넣기

첫 줄만 남기기(헤더 추출)

:1p          → 첫 줄 출력

정렬하기

:%!sort -t',' -k3 -rn    → 3번째 필드(score) 내림차순

-t','는 구분자를 콤마로 지정, -k3는 3번째 열, -rn은 역순 숫자 정렬입니다.

중복 제거

:%!sort -u

uniq보다 sort -u가 간단합니다.

필드 수가 다른 데이터 정비

:%s/\v^([^,]+),([^,]+),([^,]+)$/\3,\2,\1/   → 열 순서 바꾸기

각 (...) 그룹을 \1~\3으로 참조해 재배열합니다.

연습

  1. 예제 CSV에서 Ctrl+v로 두 번째 열만 복사
  2. :%!sort -t',' -k3 -rn로 점수순 정렬
  3. :%s/\v^([^,]+),([^,]+),([^,]+)$/\1,\3,\2/로 열 순서 변경

실습

에디터를 클릭한 뒤 키보드로 조작하세요. i 입력, Esc Normal, :w 저장(다운로드), :q! 강제 종료.
