줄 끝 공백 제거

여러 파일에서 줄 끝 공백을 한 번에 정리합니다.

상황

코드 리뷰에서 “줄 끝 공백”을 지적받았습니다. 여러 파일의 공백을 하나씩 지우는 것은 비효율적입니다.

해결

:%s/\s\+$//g

줄 끝의 공백을 모두 제거합니다.

파일을 여러 개 열어놨다면 아래처럼 한 번에 적용합니다.

:argdo %s/\s\+$//g | update
  • :argdo : 인자 목록(argument list)의 각 파일에 실행
  • | update : 변경된 파일 저장

절차

  1. vim *.js로 여러 파일 열기
  2. :argdo %s/\s\+$//g | update
  3. :qall로 모두 종료

결과 확인

:set list            → 공백 표시(^$ 등)
:set listchars=trail:·

trail 설정으로 줄 끝 공백이 보이게 할 수 있습니다. 정리 후 사라졌는지 확인하세요.

연습

  2. :%s/\s\+$//g로 제거
  3. :set list로 확인
