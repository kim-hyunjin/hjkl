매크로로 줄 끝에 세미콜론 붙이기

매크로를 기록·재생해 여러 줄을 일괄 수정하는 챌린지입니다.

목표

다음 코드에서 모든 실행문의 끝에 세미콜론을 붙이세요.

const a = 1
const b = 2
const c = a + b
console.log(c)

결과:

const a = 1;
const b = 2;
const c = a + b;
console.log(c);

조건

  • 매크로(qa~q, @a) 사용
  • 한 줄씩 수동으로 붙이지 않기
  • 매크로는 상대 이동으로 구성(줄 번호 금지)

문제 풀기

에디터를 클릭한 뒤 키보드로 조작하세요. i 입력, Esc Normal, :w 저장(다운로드), :q! 강제 종료.
