치트시트

자주 쓰는 vim 명령어를 카테고리별로 정리했습니다. 키워드로 빠르게 검색해보세요.

커서 이동

h j k l 왼쪽 / 아래 / 위 / 오른쪽
w / b 다음 단어 시작 / 이전 단어 시작
e / ge 다음 단어 끝 / 이전 단어 끝
0 / $ 줄 맨 앞 / 줄 맨 끝
^ 줄의 첫 글자(공백 제외)로
gg / G 파일 첫 줄 / 파일 마지막 줄
nG n번째 줄로 이동
Ctrl+d / Ctrl+u 반 페이지 아래 / 위
Ctrl+f / Ctrl+b 한 페이지 아래 / 위
H / M / L 화면 위 / 중간 / 아래로 이동
% 짝 괄호로 이동
f{ch} / t{ch} 같은 줄 다음 {ch} / 그 직전까지
{ / } 이전 문단 / 다음 문단

편집

i / a 커서 앞에 삽입 / 뒤에 삽입
I / A 줄 맨 앞에 삽입 / 줄 맨 끝에 삽입
o / O 아래에 새 줄 삽입 / 위에 새 줄 삽입
r 현재 글자 교체
R 대체(Replace) 모드
s / S 글자 지우고 삽입 / 줄 지우고 삽입
x / X 커서 글자 삭제 / 앞 글자 삭제
d{motion} 모션 범위 삭제
dd 한 줄 삭제
D / C 줄 끝까지 삭제 / 삭제 후 삽입
c{motion} / cc 변경(삭제+삽입) / 한 줄 변경
~ 대소문자 전환
u / Ctrl+r 실행 취소 / 다시 실행

복사·붙여넣기

y{motion} / yy 복사 / 한 줄 복사
p / P 다음에 붙여넣기 / 이전에 붙여넣기
yiw / diw / ciw 단어 복사 / 삭제 / 변경
y$ 커서부터 줄 끝까지 복사
"ayy 레지스터 a에 줄 복사
"ap 레지스터 a 붙여넣기

검색·치환

/{pattern} 아래 방향 검색
?{pattern} 위 방향 검색
n / N 다음 검색 결과 / 이전 검색 결과
* / # 커서 아래 단어 검색(아래/위)
:s/old/new/g 현재 줄에서 모두 치환
:%s/old/new/g 파일 전체 치환
:%s/old/new/gc 치환 전 확인
:%s/\v(\w+)/\1/g 정규식 그룹 치환

파일·윈도우

:w 저장
:q / :q! 종료 / 저장 없이 종료
:wq / :x 저장 후 종료
:e {file} 파일 열기
:new / :vnew 가로 분할 / 세로 분할
:sp {file} 파일을 가로 분할로 열기
Ctrl+w w 다음 분할창으로 이동
Ctrl+w h/j/k/l 방향별 분할창 이동
:bn / :bp 다음 버퍼 / 이전 버퍼
:ls 버퍼 목록
:bd 버퍼 삭제

블록·비주얼

v 문자 단위 비주얼 모드
V 줄 단위 비주얼 모드
Ctrl+v 블록 비주얼 모드
gv 이전 비주얼 선택 영역 다시 선택
o 비주얼 선택 반대 끝으로 이동
> / < 들여쓰기 / 내어쓰기

기타 유용한 명령

Ctrl+n 자동 완성(현재 버퍼)
Ctrl+p 자동 완성(역방향)
. 마지막 변경 반복
J 다음 줄과 합치기
zz / zt / zb 커서 줄을 화면 중앙 / 위 / 아래로
ma / `a 마크 설정 / 마크로 이동
qa / q / @a 매크로 기록 시작 / 중지 / 재생
:set number 줄 번호 표시
:set relativenumber 상대 줄 번호 표시
:nohlsearch 검색 하이라이트 제거
:help {topic} 도움말 열기
