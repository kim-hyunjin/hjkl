## 상황

여러 줄 각각의 **앞이나 뒤**에 같은 문자열을 붙여야 합니다.

```
apple
banana
cherry
```

각 줄 뒤에 쉼표를 붙이고 싶습니다.

## 앞에 붙이기

1. `Ctrl+v`로 블록 비주얼 모드
2. `j`로 세 줄 선택
3. `I` → `- ` 입력 → `<Esc>`

```
- apple
- banana
- cherry
```

`I`는 블록 선택 시 **각 줄의 시작**에 삽입합니다.

## 뒤에 붙이기

1. `Ctrl+v`로 블록 선택
2. `A` → `,` 입력 → `<Esc>`

```
apple,
banana,
cherry,
```

`A`는 블록 선택 시 **각 줄의 끝**에 삽입합니다.

## 중간 위치 일괄 삽입

`f{문자}`로 이동 후 `Ctrl+v` + `j` + `I`를 하면 해당 문자 위치에 일괄 삽입됩니다.

## 주의

- 블록 삽입이 적용되는 시점은 `<Esc>`를 눌렀을 때입니다.
- 마지막 줄이 끝나지 않으면 예상과 다를 수 있으니 `$`로 줄 끝까지 선택하는 것이 안전합니다.

## 연습

1. 예제 파일에 과일 목록 3~5줄 만들기
2. `Ctrl+v` + `j` + `I` + `- ` 로 앞에 붙이기
3. `Ctrl+v` + `A` + `,` 로 뒤에 붙이기
4. `u`로 원상 복구 후 다시 연습
