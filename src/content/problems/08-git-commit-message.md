## 상황

`git commit`을 실행하면 vim이 열려 커밋 메시지를 입력하게 됩니다. 처음 보면 당황하지만 몇 가지 규칙만 알면 됩니다.

## 기본 흐름

```
$ git commit
```

1. vim이 열리고 `#`로 시작하는 주석(스테이지 목록)이 보입니다.
2. 맨 위에 메시지를 입력합니다.
3. `:wq`로 저장 종료하면 커밋이 완료됩니다.

## 규칙

- 첫 번째 줄: 변경 요약 (50자 이내 권장)
- 빈 줄
- 본문: 무엇을/왜 바꿨는지
- `#` 주석은 저장해도 커밋에 포함되지 않습니다.

```
fix(auth): 로그인 실패 시 에러 메시지 표시

세션 만료 시 401이 발생하는데 이를 감지해
다시 로그인하도록 유도합니다.
```

## 효율적인 편집

```
gg          → 첫 줄로 이동
I           → 줄 맨 앞에서 입력 시작
```

본문을 쓰다가 흐름이 끊기면 `o`(아래 줄), `O`(위 줄)로 이어서 씁니다.

## 커밋 템플릿

`.gitmessage` 파일을 만들어 기본 템플릿을 적용할 수 있습니다.

```
$ git config --global commit.template ~/.gitmessage
```

```
# 제목
# 
# 본문
# 
# 꼬리말 (예: Closes #123)
```

## 커밋 메시지 수정

```
$ git commit --amend    → 마지막 커밋 메시지 수정
$ git rebase -i         → 여러 커밋 메시지 일괄 수정
```

`rebase -i`에서도 vim이 열리며, `pick`을 `reword`로 바꾸고 저장하면 해당 커밋의 메시지를 다시 입력할 수 있습니다.

## 연습

1. 실습 파일에 커밋 메시지 초안 작성
2. `gg`, `I`, `o`로 편집
3. `:wq`로 저장 (커밋 흐름 확인)
4. 커밋 템플릿을 로컬에 적용해보기
