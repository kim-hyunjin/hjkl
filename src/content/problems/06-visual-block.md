## 목표

다음 목록의 각 항목 앞에 `- `를 붙이세요.

```
apple
banana
cherry
date
```

결과:

```
- apple
- banana
- cherry
- date
```

## 조건

- `Ctrl+v` 블록 비주얼 모드 사용
- `I`(블록 시작 삽입) 사용
- 화살표 금지
