## 명령행의 세계

`:`(콜론)으로 시작하는 명령행은 vim의 **파워 유저 영역**입니다. 파일 전체, 선택 영역, 범위를 지정해 명령을 실행할 수 있습니다.

## 범위(Range)

명령 앞에 범위를 붙이면 "어디에" 적용할지 정할 수 있습니다.

```
:5            → 5번 줄로 이동
:5,10d        → 5~10번 줄 삭제
:.,$d         → 현재 줄~끝 삭제
:1,.s/foo/bar → 1번~현재 줄 치환
:%s/foo/bar   → 전체 치환
:'<,'>s/...   → 비주얼 선택 영역
```

`.`는 현재 줄, `$`는 마지막 줄, `%`는 파일 전체를 뜻합니다.

## 정규식 기초

vim 정규식은 grep과 비슷하지만 **특수 문자가 다릅니다.**

| 패턴 | 의미 |
| --- | --- |
| `.` | 임의의 문자 |
| `*` | 앞 문자의 0회 이상 |
| `\+` | 앞 문자의 1회 이상 |
| `\?` | 앞 문자의 0 또는 1회 |
| `\(...\)` | 그룹 |
| `\1` | 첫 번째 그룹 참조 |
| `\<` `\>` | 단어 경계 |
| `[a-z]` | 문자 클래스 |

매번 `\`를 붙이기 번거롭다면 **very magic** 모드를 씁니다.

```
:%s/\v(...)/\1/g
```

`\v` 이후부터는 `( ) + ? |` 등을 이스케이프 없이 쓸 수 있습니다.

## 실전 치환 패턴

```
:%s/\v(\w+) (\w+)/\2 \1/        → 앞뒤 두 단어 순서 바꾸기
:%s/\v"([^"]*)"/'\1'/g          → 큰따옴표를 작은따옴표로
:g/^$/d                         → 빈 줄 제거
:%s/\v\s+$//                    → 줄 끝 공백 제거
```

> 그룹 `\v(...)`으로 묶고 `\1`, `\2`로 되받는 것이 치환의 핵심입니다. 순서 바꾸기, 따옴표 교체, 포맷 정리 대부분이 이 조합으로 해결됩니다.

## 명령행에서 셸과 연동

```
:!ls              → 셸 명령 실행
:r !date          → 셸 출력을 버퍼에 삽입
:%!sort           → 버퍼 전체를 sort 결과로 교체
:2,$!sort -t',' -k2   → 범위 필터
```

`:%!{command}`는 **버퍼를 파이프로** 처리하는 고급 기능입니다. 정렬, 유니크, 포맷 등 어떤 것도 가능합니다.

## 히스토리

명령행 히스토리는 `Ctrl+p`/`Ctrl+n`으로 탐색하고, `q:`로 명령 히스토리 창을 엽니다.

## 연습

1. `:%s/\v\s+$//`로 줄 끝 공백 제거
2. `:1,.s/foo/bar/g`로 범위 치환
3. `:g/foo/d`로 `foo`가 든 줄만 삭제

다음 강의는 **텍스트 객체와 `.` 반복**으로 편집 효율을 극대화합니다.
