## 방향키 대신 h j k l

vim은 화살표 대신 다음 키로 커서를 움직입니다. 오른손 홈 포지션에서 바로 닿는 위치라 손가락이 키보드를 떠날 필요가 없습니다.

| 키 | 방향 |
| --- | --- |
| `h` | 왼쪽 |
| `j` | 아래 |
| `k` | 위 |
| `l` | 오른쪽 |

**기억 꿀팁:** `j`는 아래로 내려가는 갈고리 모양, `k`는 위로 올라가는 모양이라고 생각하면 쉽습니다.

> 화살표 키도 동작하지만, 익숙해지려면 의도적으로 `hjkl`만 사용해보세요.

## 반복 횟수를 앞에 붙이기

vim 명령은 **숫자를 앞에 붙여 반복**할 수 있습니다.

```
3j   → 아래로 3칸
5l   → 오른쪽으로 5칸
2k   → 위로 2칸
```

이 방식은 이동뿐 아니라 나중에 배울 삭제(`d3w`), 변경(`c2j`) 등 모든 명령에 적용됩니다.

## 단어 단위 이동

문자 하나하나 움직이는 것은 느립니다. 단어 단위로 이동하면 훨씬 빠릅니다.

| 키 | 동작 |
| --- | --- |
| `w` | 다음 단어의 **시작**으로 |
| `b` | 이전 단어의 **시작**으로 |
| `e` | 다음 단어의 **끝**으로 |
| `ge` | 이전 단어의 **끝**으로 |

```
The quick brown fox
^   ^    ^     ^
```

커서가 줄 맨 앞에 있을 때 `w` 3번이면 `quick`, `brown`, `fox`로 이동합니다.

## 줄의 시작과 끝

| 키 | 동작 |
| --- | --- |
| `0` | 줄의 맨 처음(열 0) |
| `^` | 줄의 첫 번째 글자(공백 제외) |
| `$` | 줄의 맨 끝 |

## 파일 전체 이동

| 키 | 동작 |
| --- | --- |
| `gg` | 파일의 첫 줄 |
| `G` | 파일의 마지막 줄 |
| `<n>G` | n번째 줄 |
| `Ctrl+d` / `Ctrl+u` | 반 페이지 아래 / 위 |
| `Ctrl+f` / `Ctrl+b` | 한 페이지 아래 / 위 |

## 짝 괄호로 이동

```
if (foo) {
    bar();
}
```

`%` 키를 괄호 위에 놓고 누르면 **짝이 되는 괄호**로 점프합니다. `if`의 `(`에서 `%`를 누르면 `)`로 이동합니다.

## 연습

1. `gg`로 첫 줄로 이동
2. `G`로 마지막 줄로 이동
3. `w` 5번으로 단어를 하나씩 이동
4. `$`로 줄 끝, `0`으로 줄 시작 이동
5. `%`로 괄호 사이 점프

> 이 강의는 아래 실습에서 바로 해볼 수 있습니다. `w`, `b`, `e`를 손에 익히는 것이 목표입니다.
