## 저장과 종료 명령

| 명령 | 동작 |
| --- | --- |
| `:w` | 저장 |
| `:w {file}` | 다른 이름으로 저장 |
| `:q` | 종료 |
| `:q!` | 변경 사항 버리고 종료 |
| `:wq` | 저장 후 종료 |
| `:x` | 저장 후 종료 (`:wq`와 유사) |
| `ZZ` | 저장 후 종료 (Normal 모드) |
| `ZQ` | 버리고 종료 |

`:q`는 변경 사항이 있으면 거부합니다. 파일을 닫기 전에 저장했는지 확인하는 안전장치입니다.

```
E37: No write since last change (add ! to override)
```

## 파일 열기

| 명령 | 동작 |
| --- | --- |
| `vim file.txt` | 터미널에서 열기 |
| `:e file.txt` | vim 안에서 다른 파일 열기 |
| `:e!` | 저장하지 않은 변경을 버리고 다시 로드 |
| `:r file.txt` | 현재 파일에 다른 파일 내용 삽입 |

`:e`로 새 파일을 열면 기존 파일이 **버퍼**로 남아 있습니다. 저장하지 않은 변경이 있으면 `:e!`로 강제로 바꿀 수 있습니다.

## 여러 파일 열기

```
$ vim a.txt b.txt c.txt
```

처음에는 `a.txt`가 열립니다. 다음 버퍼로 이동하려면 다음 명령을 씁니다.

```
:bn     다음 버퍼
:bp     이전 버퍼
:ls     버퍼 목록
:b3     버퍼 3번으로 이동
:bd     버퍼 닫기
```

## 저장 없는 종료 조심

vim을 처음 쓰면 "어떻게 나가지?"에서 막히는 경우가 많습니다. 순서를 외워두세요.

```
:q!  → (무조건 나가기)
:w   → (저장)
:wq  → (저장하고 나가기)
```

## 터미널과 상호작용

실제 터미널 vim에서는 `:!{명령}`으로 셸 명령을 실행할 수 있습니다.

```
:!ls        → 디렉토리 목록 보기
:!pwd       → 현재 경로
:$!sort %   → 버퍼를 셸 명령으로 처리 (유닉스)
```

브라우저 실습에서는 셸 명령이 지원되지 않지만, 로컬 vim에서는 유용합니다.

## 연습

1. `:w`로 저장
2. `:e other.md`로 다른 파일 열기
3. `:bn`/`:bp`로 버퍼 이동
4. `:wq`로 저장 종료
5. `vim a b c`로 열어 `:ls` 확인
