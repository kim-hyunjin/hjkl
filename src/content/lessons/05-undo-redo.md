## u로 실행 취소

Normal 모드에서 `u`를 누르면 **마지막 변경을 취소**합니다.

```
Hello World
```

1. `dd`로 줄 삭제
2. `u` → 다시 나타남

`u`는 변경 단위(명령 단위)로 취소합니다. 한 번의 연속 입력은 하나의 변경으로 묶입니다.

## Ctrl+r로 다시 실행

`Ctrl+r`(redo)은 취소한 것을 **다시 적용**합니다.

```
dd  → 삭제
u   → 복구
Ctrl+r → 다시 삭제
```

`u`와 `Ctrl+r`은 짝입니다. 취소한 뒤 다시 실행하려면 `Ctrl+r`입니다.

## 명령 번호 붙이기

```
3u      → 3단계 취소
2Ctrl+r → 2단계 재실행
```

일부 vim 설정에서는 `U`(현재 줄의 모든 변경 취소)도 있습니다. `u`로는 부족할 때 줄 단위로 되돌리고 싶다면 `U`를 시험해보세요.

## 브랜치형 언두

vim의 undo는 **선형이 아니라 브랜치**를 이룹니다.

```
변경 A → 변경 B → 변경 C
  ↑ u로 돌아감
  → 다시 다른 변경 D
```

`u`로 A까지 돌아간 뒤 새 변경 D를 만들면, B, C로는 다시 갈 수 없습니다. 대신 `:undolist`와 `g-`, `g+`로 언두 브랜치를 탐색할 수 있습니다.

## 실수 방지 팁

- 뭔가 잘못됐다면 일단 `u`
- 저장하기 전에 `:w` (저장 후 다시 편집 가능)
- 실수로 저장했다면 `~/.viminfo` 등 백업/스왑 파일을 확인

> **Tip:** 커밋과 마찬가지로 "자주 저장 + 가끔 취소"가 가장 안전합니다.

## 연습

1. 아무 텍스트나 몇 줄 입력
2. `u` 여러 번으로 입력 취소
3. `Ctrl+r` 여러 번으로 다시 실행
4. `dd` 후 `u` 후 `Ctrl+r` 흐름 체험

이제 편집의 기본기를 갖췄습니다. 다음 강의는 **복사·붙여넣기(yank/paste)**입니다.
