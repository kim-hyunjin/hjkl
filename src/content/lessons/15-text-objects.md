## 텍스트 객체란

텍스트 객체는 **구조적인 단위**를 지정해 삭제·변경·복사하는 표기입니다. 형태는 항상 다음과 같습니다.

```
{명령}{i 또는 a}{객체}
```

- `i` = inner : 공백/구분자 제외
- `a` = around : 공백/구분자 포함

## 대표 객체

| 객체 | 예 | 의미 |
| --- | --- | --- |
| `w` | `ciw` | 단어 |
| `s` | `das` | 문장 |
| `p` | `dap` | 문단 |
| `"` | `ci"` | 큰따옴표 안 |
| `'` | `di'` | 작은따옴표 안 |
| `` ` `` | `yi`` | 백틱 안 |
| `(` 또는 `b` | `di(` | 괄호 안 |
| `[` | `ci[` | 대괄호 안 |
| `{` 또는 `B` | `di{` | 중괄호 안 |
| `<` | `di<` | 꺾쇠 안 |
| `t` | `dit` | HTML 태그 안 |

## 실전 예제

```js
const message = "hello world";
```

| 명령 | 결과 |
| --- | --- |
| `ci"` | `"` 안의 `hello world`를 지우고 입력 모드 |
| `di"` | `hello world`만 삭제 (따옴표 유지) |
| `yi"` | `hello world` 복사 |
| `da"` | `"hello world"` 통째로 삭제 |

괄호 위에 커서가 있으면 `ci(`는 **중첩된 괄호의 안쪽**만 정확히 선택합니다. `%`로 짝을 찾는 것보다 훨씬 강력합니다.

## 객체 조합

텍스트 객체는 숫자와 결합할 수 있고, `c` 외에도 모든 명령과 함께 쓸 수 있습니다.

```
ciw   → 단어 교체
ci"   → 따옴표 안 교체
diB   → 중괄호 안 삭제
yi(   → 괄호 안 복사
va'   → 작은따옴표 포함 선택
```

## `gq`와 결합

텍스트 객체 `gqap`는 문단을 **포맷(재정렬)** 합니다. 주석 정리에 유용합니다.

## 연습

1. `ci"`로 따옴표 안 교체
2. `di(`로 괄호 안 삭제
3. `yi'`로 따옴표 안 복사 후 붙여넣기
4. `vaw`로 "단어+공백" 선택 확인

다음 강의는 **autocommand와 옵션**으로 vim을 자신의 도구로 커스터마이즈합니다.
