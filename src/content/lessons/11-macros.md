## 매크로란

매크로는 **일련의 키 입력을 레지스터(a~z)에 기록**하고, 필요할 때 재생하는 기능입니다. 같은 작업을 100번 반복해야 한다면 1번만 배워서 100번 실행할 수 있습니다.

## 기본 흐름

```
qa        → a 레지스터에 매크로 기록 시작
(동작 수행)
q         → 기록 종료
@a        → 매크로 재생
@@        → 마지막 매크로 다시 재생
100@a     → 100번 반복 재생
```

## 실전 예제

다음 텍스트에서 각 줄의 끝에 `,`를 붙이고 싶다고 가정합시다.

```
apple
banana
cherry
```

1. 첫 줄로 이동: `gg`
2. 매크로 기록 시작: `qa`
3. 줄 끝으로 이동 후 `,` 추가: `A,<Esc>`
4. 다음 줄로 이동: `j`
5. 기록 종료: `q`
6. 나머지 줄에 재생: `99@a`

이제 99번 반복했지만 실제 줄이 3개뿐이므로 나머지는 끝에서 멈춥니다.

## 재생 중 실수 처리

- 재생 도중 문제가 생기면 `Ctrl+c`로 중단
- 매크로를 덮어쓰려면 같은 레지스터에 다시 기록
- `:reg a`로 레지스터 내용 확인

## 명령행에서 매크로 사용

레지스터에 저장된 매크로는 `:normal` 명령에서도 쓸 수 있습니다.

```
:'<,'>normal @a   → 선택 영역의 각 줄에서 매크로 재생
```

## 팁: 매크로는 상대 이동으로

매크로 안에서는 절대 줄 번호(`5G`)보다 **상대 이동**(`j`, `w`, `f`)을 쓰는 것이 안전합니다. 그래야 매 줄에서 동일하게 동작합니다.

## 연습

1. `qa`로 `A;<Esc>j` 기록
2. `@a`로 재생
3. 텍스트 여러 줄에서 `99@a`로 일괄 적용
4. `:reg a`로 내용 확인

매크로는 vim 숙련도의 분수령입니다. 다음 강의는 **버퍼·탭·분할창**으로 여러 파일을 다루는 법을 배웁니다.
