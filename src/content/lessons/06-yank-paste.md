## yank: 복사

복사 명령은 `y`(yank)입니다. `d`처럼 모션과 결합합니다.

| 명령 | 동작 |
| --- | --- |
| `yw` | 단어 복사 |
| `y$` | 커서부터 줄 끝까지 복사 |
| `yy` | 현재 줄 복사 |
| `y2j` | 현재 줄과 아래 2줄 복사 |
| `yiw` | 커서 안쪽 단어 복사 |
| `yG` | 커서부터 파일 끝까지 복사 |

```
The quick brown fox
```

커서가 `quick`의 `q`에 있을 때 `yw`를 누르면 `quick`이 복사됩니다.

## paste: 붙여넣기

| 키 | 동작 |
| --- | --- |
| `p` | 커서 **다음**(아래 줄)에 붙여넣기 |
| `P` | 커서 **이전**(위 줄)에 붙여넣기 |

줄 단위(`yy`)로 복사했으면 `p`는 **아래에 새 줄**로 붙여넣고, 글자 단위(`yw`)면 커서 바로 다음에 붙여넣습니다.

```
yy  → "Hello" 줄 복사
p   → 아래에 "Hello" 줄 추가
```

## 레지스터 개념 예고

복사하거나 삭제한 내용은 `"` 레지스터에 들어갑니다.

```
"ayy   → a 레지스터에 줄 복사
"ap    → a 레지스터 붙여넣기
```

레지스터 이름은 `a`~`z`로 여러 개를 쓸 수 있습니다. 자세한 내용은 심화 강의에서 다룹니다.

## 잘라내기(cut)는 삭제 그 자체

`dd`로 지운 내용은 레지스터에 남기 때문에 `p`로 붙여넣을 수 있습니다. 즉 vim에서 **삭제 = 잘라내기**입니다.

```
dd   → 줄 잘라내기 (레지스터에 저장)
p    → 그 줄 붙여넣기
```

## 실무 패턴

1. `yy`로 줄 복사
2. `j`로 내려가서 `p`로 붙여넣기
3. 필요하면 `dd`로 제거
4. `u`로 실수 복구

## 연습

1. `yy` 후 `p`로 줄 복제
2. `yw`로 단어 복사 후 `p`로 붙여넣기
3. `dd` 후 `p`로 줄 이동(잘라내기 효과)
4. `"ayy`, `"ap`로 레지스터 사용

다음 강의는 **검색과 치환**입니다. 긴 파일에서 원하는 곳으로 이동하고 바꾸는 능력은 생산성에 큰 영향을 줍니다.
