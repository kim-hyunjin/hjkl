## 마크(Mark)

마크는 **텍스트 위치에 북마크**를 거는 기능입니다. 소문자 `a`~`z`는 파일 내부 마크, 대문자 `A`~`Z`는 다른 파일에도 유효한 전역 마크입니다.

| 명령 | 동작 |
| --- | --- |
| `ma` | 현재 커서 위치를 a로 마크 |
| `` `a `` | a 마크 위치로 정확히 이동 |
| `'a` | a 마크가 있는 줄의 시작으로 이동 |
| `:marks` | 마크 목록 |
| `:delmarks a` | 마크 삭제 |

```
ma          → 위치 저장
(다른 곳으로 이동)
`a          → 저장한 위치로 점프
```

마크는 함수 정의 위에 걸어두고 코드를 탐색하다가 다시 돌아오는 데 유용합니다.

## 자동 마크

vim은 몇 가지 마크를 자동으로 관리합니다.

```
`"    → 마지막으로 편집한 위치
`.    → 마지막 변경 위치
`0    → 마지막으로 연 파일
```

## 레지스터(Register)

레지스터는 클립보드 이상의 **여러 저장 공간**입니다.

| 레지스터 | 용도 |
| --- | --- |
| `"` (unnamed) | 기본 yank/delete 대상 |
| `a`~`z` | 사용자 지정 |
| `0` | 마지막 yank 전용 |
| `1`~`9` | 최근 삭제 이력 |
| `+` | 시스템 클립보드(OS) |
| `*` | X11 선택 버퍼 |
| `%` | 현재 파일 경로 |
| `:` | 마지막 명령행 |

## 레지스터 사용

```
"ayy      → a 레지스터에 줄 복사
"ap       → a 레지스터 붙여넣기
"+yy      → 시스템 클립보드에 복사
"+p       → 시스템 클립보드에서 붙여넣기
:reg      → 전체 레지스터 보기
:reg a b  → 특정 레지스터 보기
```

삭제한 내용은 `1`~`9`에 쌓이므로 실수로 덮어써도 이전 삭제 내용을 꺼낼 수 있습니다.

```
"1p       → 가장 최근 삭제 내용 붙여넣기
```

## 클립보드 설정

실제 터미널 vim에서 시스템 클립보드를 쓰려면 vim이 `+clipboard`로 컴파일되어 있어야 합니다.

```
:echo has('clipboard')   → 1이면 사용 가능
:set clipboard=unnamedplus   → y/p가 시스템 클립보드와 연동
```

## 연습

1. `ma` 후 이동, `` `a ``으로 복귀
2. `"ayy`, `"ap`로 레지스터 a 사용
3. `"1p`로 최근 삭제 복원
4. `:reg`로 전체 레지스터 확인

다음 강의는 **명령행과 정규식**으로 강력한 치환과 필터를 배웁니다.
